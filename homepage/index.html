mindgame

MITM audit proxy for AI agents. Intercept HTTPS, enforce intent declarations, score every request for risk.

$ docker pull ghcr.io/perbu/mindgame click to copy
Deployment

Sits between agents and the internet

Runs as a container on both the internal agent network and the external network. Agents have no direct internet access. All traffic flows through Mindgame.

Request Lifecycle

Risk Scoring

CEL-powered heuristics

Scoring rules are CEL expressions stored in the database. Edit them at runtime. No recompile. No restart.

scoring_rules 
// Flag sensitive paths
path.matches("(?i)/\\.env|/\\.git|/admin")
  // +5 points

// Credential patterns in body
body.matches("(?i)bearer [a-z0-9_-]+|sk-[a-z0-9]+")
  // +8 points

// Confidential content
body.matches("(?i)confidential|secret|api_key")
  // +5 points

// Large outbound POST
method == "POST" && body_size > 65536
  // +3 points

Score determines action

Points accumulate across all matching rules. Thresholds are evaluated for default-tier traffic.

0–9
ALLOW
10–19
BLOCK
20+
BAN

Bans add the host to the deny list with a banned flag. Requires human review to lift. Allowed-tier domains are never blocked — score is recorded for forensics only.

Features

What's in the box

⚙
HTTPS Interception
Full MITM via CONNECT tunneling. Auto-generates a CA on first run, mints certs on the fly.
▦
SQLite Audit Log
Every request and response. Full headers, full bodies. One file, queryable with standard tools.
⇄
Web UI
Live request feed via SSE. Domain and scoring rule management. Statistics dashboard. Built with templ + HTMX.
◆
Dynamic Bans
High-risk scores automatically ban the host. Distinguished from manual rules. Reviewable via UI.
☷
Single Binary
Go binary with embedded UI assets. No runtime dependencies. Runs in a container or bare metal.
❖
Dream Mode
Ambient full-screen visualization of live traffic. Designed for NOC wall displays. Particle-based, color-coded by risk.
Quick Start

Running in 60 seconds

Drop Mindgame next to your agents. Internal network for agents, Mindgame bridges to the outside.

standalone 
# Run with a persistent volume
$ docker run -p 8080:8080 -p 9090:9090 -v mindgame-data:/data ghcr.io/perbu/mindgame
docker-compose.yml 
services:
  mindgame:
    image: ghcr.io/perbu/mindgame:latest
    ports:
      - "9090:9090"  # Web UI
    volumes:
      - ./data:/data
    networks:
      - internal
      - external

  agent:
    image: your-agent:latest
    environment:
      - http_proxy=http://mindgame:8080
      - https_proxy=http://mindgame:8080
      - NODE_EXTRA_CA_CERTS=/certs/ca.pem
    volumes:
      - ./data/ca.pem:/certs/ca.pem:ro
    networks:
      - internal  # no direct internet

networks:
  internal:
    internal: true  # isolated, no egress
  external:
